# 03: Core Features of Terpa Web

This section provides detailed documentation for the major features and functionalities available in the Terpa Web application. Each document below focuses on a specific domain, explaining its purpose, key components, and how it operates.

## Feature Documentation Index

- [**User Management**](./user_management.md):
  - Covers user profiles, settings, and related functionalities beyond basic authentication.
- [**Team Management**](./team_management.md):
  - Details on creating, managing teams, member roles, and permissions within teams.
- [**Machine Management**](./machine_management.md):
  - In-depth information on machine CRUD operations, properties (location, status, settings), sales tracking, and other machine-specific features.
- [**Inventory Management**](./inventory_management.md):
  - Explanation of product management, inventory controls (spirals, picklists), and stock operations.
- [**Route Management**](./route_management.md):
  - Documentation on defining service/collection routes and assigning machines to them.
- [**Incident Management**](./incident_management.md):
  - Covers the process of logging, tracking, and resolving operational incidents.
- [**Billing and Invoicing**](./billing_and_invoicing.md):
  - Details on invoice generation, payment processing (including MercadoPago integration), and handling of payment proofs.
- [**Admin Dashboard**](./admin_dashboard.md):
  - Overview of the administrative dashboard, its key functionalities, data tables, and reporting capabilities.

Please select a feature from the list above to learn more about its specific implementation in Terpa Web.

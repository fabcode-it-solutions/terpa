# 01: Getting Started with Terpa Web

This section provides practical guidance for developers to set up their local development environment, install necessary dependencies, and get the Terpa Web application running.

## Documents in this Section

- [**Setup and Installation**](./setup_and_installation.md):
  - A step-by-step guide covering prerequisites.
  - Cloning the repository.
  - Installing project dependencies.
  - Configuring environment variables.
  - Setting up and seeding the database.
  - Running the development server.
  - Basic commands for linting and building the project.

Following the steps in [Setup and Installation](./setup_and_installation.md) will help you quickly get a local instance of Terpa Web operational.
